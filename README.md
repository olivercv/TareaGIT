# Tarea Git

## Descripción

Este proyecto es una tarea simple creada únicamente para **probar GitHub** y practicar con los comandos básicos de control de versiones con Git.

No contiene funcionalidad compleja, solo es para familiarizarse con:
- Crear repositorios
- Hacer commits
- Trabajar con ramas
- Hacer push a un repositorio remoto

---

**Nota:** Este es un proyecto de prueba para propósitos educativos.
